# دانلود ارائهٔ تیتانا

فایل آماده: [titana-campaign-intelligence.html](titana-campaign-intelligence.html)

در صفحهٔ فایل GitHub، گزینهٔ **Download raw file** را بزنید. در Preview روی **«دریافت نسخهٔ آفلاین HTML»** بزنید. صفحهٔ دانلود در زبانهٔ تازه باز می‌شود؛ آنجا **«دانلود فایل HTML»** را بزنید. اگر زبانه باز نشد، ابتدا گزینهٔ **Open in new tab** خود Preview را بزنید و دوباره تلاش کنید. دانلود مستقیم داخل بعضی Previewهای تعبیه‌شده محدود است.

## استفاده

۱. فایل HTML را روی دستگاه ذخیره کنید.
۲. آن را با مرورگر به‌روز باز کنید. برای دیدن متن، فونت، فرم‌ها، نمودارها و ساخت QR به اینترنت، نصب بسته یا اجرای سرور نیاز نیست.
۳. برای PDF از دکمهٔ چاپ داخل فایل استفاده کنید. نسخهٔ چاپی شامل همهٔ جزئیات فنی است.

این فایل دقیقاً با فایل اصلی ارائه یکسان است؛ فقط یک فایل برای انتقال کافی است. حجم فعلی حدود ۵۱۹ کیبی‌بایت است. فونت، کتابخانهٔ QR و اعلان‌های مجوز داخل آن هستند.

## محدودهٔ کارکرد

- خروجی، نسخهٔ اصلی نمونه است؛ فیلتر فعلی، لینک‌های ساخته‌شده توسط شما و تغییرهای موقت جلسه را ذخیره نمی‌کند.
- لینک‌های کوتاه و آمار، نمایشی‌اند. فایل سرویس انتقال، پایگاه داده یا اتصال سفارش واقعی ندارد؛ لینک کوتاه را عمومی منتشر نکنید.
- لینک‌های تازه با بارگذاری دوبارهٔ فایل از بین می‌روند. علامت‌های چک‌لیست، در صورت پشتیبانی مرورگر، فقط روی همان دستگاه نگهداری می‌شوند.
- اجرای کامل روی Chromium در محیط آزمون انجام شده است. تضمین نبود همهٔ باگ‌ها در همهٔ مرورگرها داده نمی‌شود؛ جزئیات و محدودیت‌ها در [گزارش QA](../titana-campaign-intelligence-QA.md) ثبت شده‌اند.

## سرور Preview

```bash
python scripts/preview_server.py --port 3000
```

سرور روی `0.0.0.0` اجرا می‌شود و برای `?download=html` هدر `Content-Disposition: attachment` می‌فرستد. برای Preview از همین سرور استفاده کنید؛ یک سرور استاتیک ساده صفحهٔ دانلود اختصاصی را پیاده نمی‌کند. فایل دانلودشده همچنان بدون سرور و اینترنت کار می‌کند.

## ساخت دوباره و آزمون برای تیم فنی

```bash
node scripts/export-titana.cjs
node scripts/export-titana.cjs --check
node tests/titana-download.cjs
TITANA_HTML=.cache/qa-download/titana-campaign-intelligence.html TITANA_QA_DIR=.cache/qa-download-full node tests/titana-campaign-intelligence.cjs
node tests/titana-content-editorial.cjs
```

قبل از تست‌ها، بسته‌های توسعهٔ مشخص‌شده در گزارش QA را نصب کنید. ساخت خروجی به بستهٔ اضافی نیاز ندارد. پس از هر تغییر در HTML اصلی، خروجی را دوباره بسازید؛ دستور `--check` در صورت اختلاف فایل‌ها خطا می‌دهد. فایل‌های موقت آزمون داخل `.cache` هستند و در Git نگهداری نمی‌شوند.
